A tiny Python program that writes one funny line pitching the worst pizza topping ever: a toothpaste-and-anchovy pizza that leaves your breath minty fresh and your soul quietly filing for divorce. Built for make.fun's "The Worst Pizza Topping" bounty — one line, under 200 characters, judged on how terrible the topping sounds and how hard the joke lands.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Standard library only, fully deterministic — every run writes the exact same bytes. The entry itself:

> Try our new toothpaste-and-anchovy pizza: every bite leaves your breath minty fresh and your soul quietly filing for divorce.
